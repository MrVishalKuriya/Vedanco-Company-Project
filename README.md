# Vedanco - Swadeshi Roots, Global Reach

## Proposed System

A centralized web-based platform for showcasing Vedanco products and brand identity.

**Manages:**
*   **Product display and categorization**: Organized listing of products.
*   **Natural & Ayurvedic product details**: In-depth information on ingredients and benefits.
*   **Customer inquiries and support**: Direct communication channel via contact form.
*   **Brand information and vision**: Showcasing the "Swadeshi Roots, Global Reach" philosophy.
*   **Online visibility and digital reach**: Expanding market presence.
*   **User-friendly browsing experience**: Intuitive navigation and responsive design.

## Proposed System – Advantages

*   **Brand Visibility**: Helps Vedanco reach national & global customers.
*   **24/7 Availability**: Customers can access product info anytime.
*   **Trust & Credibility**: A professional website builds brand confidence.
*   **Better Product Presentation**: Clear display of ingredients & benefits.
*   **Customer Engagement**: Users can send queries and feedback easily via the Contact form.
*   **No Manual Effort**: Reduces dependency on physical marketing.
*   **Digital Growth**: Supports SEO and digital branding.

## Technology Used

### Frontend Technologies
*   **HTML**: Page structure and content layout.
*   **CSS**: Vanilla CSS for custom styling, responsiveness, and layout design.
*   **JavaScript**: Adds interactivity and performs client-side validation.
*   **React.js**: For building fast and responsive UI components.
*   **React Icons**: For modern, vector-based icons.

### Backend Technologies
*   **Node.js**: For handling backend logic and server operations.
*   **Express.js**: For API endpoints and server-side routing.

### Database
*   **MongoDB**: For storing contact form submissions and potential product data.

### Development Tools
*   **VS Code**: Code editing and development environment.
*   **Git & GitHub**: Source code version control.
*   **Vite**: Fast frontend build tool.

## Features
*   **Mobile Friendly**: Accessible on phones, tablets, and desktops.
*   **Cost Effective**: Reduces need for offline promotion.
*   **Future Ready**: Can be expanded to e-commerce or online ordering.
